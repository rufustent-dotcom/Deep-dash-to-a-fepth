# AI Strategic Intelligence Vault

An interactive strategic intelligence workspace and pattern mapping index powered by Gemini, synthesizing signals, patterns, active projects, and Obsidian-style database folders.

## Features

- **Strategic Signal & Pattern Mapping**: Real-time cross-referencing between macroeconomic signals, operational leverage patterns, and impact scenarios.
- **Obsidian-Style Vault Management**: Organize knowledge, research, decisions, and experiments across structured vault folders.
- **Gemini Intelligence Synthesis**: Server-side AI synthesis of market signals, automatic categorization, and strategic forecasts.
- **Persistent Vault & Social Community**: Collaborative feed and profile management backed by Firebase Firestore.

## Scripts

- `npm run dev`: Start the Next.js development server on port 3000.
- `npm run build`: Compile the production build artifacts into `dist/` and `.next/`.
- `npm run start`: Launch the production Express server hosting the Next.js app.
- `npm run lint`: Run ESLint validation across the codebase.
